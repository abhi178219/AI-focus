# Afinue — Frontend Source

React + TypeScript + Vite frontend for the Afinue alternative investment platform.

See the [project README](../README.md) for full product context, feature overview, and design decisions.

## Quick Start

```bash
npm install
echo "GEMINI_API_KEY=your_key_here" > .env.local
npm run dev   # → http://localhost:3000
```

## Scripts

| Command | Description |
|---|---|
| `npm run dev` | Start development server |
| `npm run build` | Production build |
| `npm run lint` | TypeScript type check |
| `npm run preview` | Preview production build |
